§ Useful commands

Inspect the running stack from the terminal

Watch a connector
docker logs -f np-conn-k8s
docker logs -f np-conn-cloudwatch
docker logs -f np-conn-security
Inspect a Kafka topic
docker exec -it np-kafka \
  /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 \
  --topic raw.k8s-events --from-beginning
Query the Query API directly
curl http://localhost:8090/api/v1/stats
curl 'http://localhost:8090/api/v1/search?sev=ERROR'
curl 'http://localhost:8090/api/v1/recent?n=10'
Stop / restart everything
docker compose down       # stop
docker compose down -v    # stop + wipe data
docker compose up -d      # start
docker compose ps         # status
